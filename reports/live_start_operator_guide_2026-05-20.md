# Live Start Operator Guide - 2026-05-20

## 지금 상태
- 어제 넣은 `KRW-BTC` 지정가 매수 주문 1개가 아직 안 끝났습니다.
- 상태는 `wait` 입니다. 뜻은 "아직 안 샀고, 주문이 줄 서 있음" 입니다.
- 이 주문 때문에 현금 일부가 잠겨 있습니다.
- 그래서 오늘 새 주문은 바로 넣으면 안 됩니다.

## 내가 해줘야 하는 것
1. 업비트 앱을 엽니다.
2. 주문 내역 또는 미체결 메뉴로 갑니다.
3. `KRW-BTC` 매수 주문이 있는지 봅니다.
4. 가격이 `100,000,000`이고 수량이 `0.0001`인 주문을 찾습니다.
5. 아래 둘 중 하나를 고릅니다.

## 선택 A: 기다리기
- 아무 것도 누르지 않습니다.
- 이 경우 시스템은 새 주문을 넣지 않습니다.
- 주문이 체결되면 다시 확인합니다.

## 선택 B: 직접 취소하기
- 업비트 앱에서 해당 `KRW-BTC` 미체결 주문의 취소 버튼을 누릅니다.
- 취소가 끝나면 다시 이 프로젝트를 실행합니다.
- 그때 오픈오더가 `0`이면 실전 시작 게이트를 다시 통과시킬 수 있습니다.

## 오늘 BRAIN 판단
- 뉴스는 `DEFENSIVE_REFERENCE` 입니다. 뜻은 "조심 모드" 입니다.
- 10년차 트레이더 위원회는 통과하지 못했습니다.
- whale money operator는 호가 압력이 좋지 않다고 봤습니다.
- 그래서 오늘 새 주문 판단은 `STOP` 입니다.

## 하면 안 되는 것
- 같은 주문을 한 번 더 넣지 않습니다.
- 자동 재시도하지 않습니다.
- 시장가 매수/매도하지 않습니다.
- 시스템에서 취소 API를 자동으로 호출하지 않습니다.
